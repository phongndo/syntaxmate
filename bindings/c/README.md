# Syntaxmate for C and C++

A C ABI (`libsyntaxmate`) over the shared
[binding boundary](../boundary/src/lib.rs), plus a header-only C++17 wrapper.

- [`include/syntaxmate.h`](include/syntaxmate.h): the C API, generated by
  cbindgen from [`src/lib.rs`](src/lib.rs). Its comments are the reference.
- [`include/syntaxmate.hpp`](include/syntaxmate.hpp): RAII C++ wrapper.

## Build

From `bindings/`:

```sh
cargo build -p syntaxmate-ffi --release
```

This produces `target/release/libsyntaxmate.so` (`.dylib` on macOS) and
`target/release/libsyntaxmate.a`. The default `bundled-grammars` feature embeds
every grammar; build with `--no-default-features` for a smaller library that
loads grammar bundles through `sm_engine_from_bundle`.

`make -C bindings/c install PREFIX=/usr/local PROFILE=release` installs the
libraries, both headers, a pkg-config file, and a CMake package.

## Link

| Method | Flags |
| --- | --- |
| Shared | `-I<prefix>/include -L<prefix>/lib -lsyntaxmate` |
| Static | `-I<prefix>/include <prefix>/lib/libsyntaxmate.a -lpthread -ldl -lm` on Linux; the archive alone on macOS |
| pkg-config | `pkg-config --cflags --libs syntaxmate`; `--static` adds the archive's system libraries |
| CMake | `find_package(syntaxmate REQUIRED)` and link `syntaxmate::syntaxmate` |

The C++ wrapper needs only `syntaxmate.hpp` and the same library.

## C API

```c
#include <stdio.h>
#include <string.h>
#include "syntaxmate.h"

int main(void) {
    const char *source = "fn main() {}\n";
    sm_engine *engine = NULL;
    sm_theme *theme = NULL;
    sm_string *html = NULL;

    if (sm_engine_bundled(&engine) != SM_OK ||
        sm_theme_bundled("github-dark", strlen("github-dark"), &theme) != SM_OK ||
        sm_engine_html(engine, "rust", 4, source, strlen(source), theme, NULL, &html,
                       NULL) != SM_OK) {
        fprintf(stderr, "syntaxmate: %s\n", sm_last_error_message());
    } else {
        fwrite(sm_string_data(html), 1, sm_string_len(html), stdout);
    }
    sm_string_free(html);
    sm_theme_free(theme);
    sm_engine_free(engine);
    return 0;
}
```

Conventions:

- **Status codes.** Fallible functions return `sm_status`: `SM_OK` (0) or a
  stable error code shared with every binding. Results go to out-parameters;
  a handle out-parameter is set to NULL on failure. Accessors that cannot fail
  (`sm_string_data`, `sm_string_list_get`, `sm_theme_name`, …) and the
  `sm_*_free` functions return their value directly and accept NULL.
- **Error detail** is thread-local: `sm_last_error_message()` describes the
  last failed call on the calling thread, or returns NULL after a success. The
  message stays valid until the next status-returning call on that thread.
- **Inputs** are UTF-8 `(pointer, length)` pairs and need not be
  NUL-terminated. NULL with length 0 is an empty string. NULL handles or
  out-parameters, NULL text with a nonzero length, invalid UTF-8, and unknown
  enum values return `SM_INVALID_INPUT`. A Rust panic returns `SM_INTERNAL`.
- **Ownership.** Everything returned is freed by its `sm_*_free` function.
  Borrowed data (`sm_str`, `sm_token_view`) lives until its owner is freed.
  Returned strings end with a NUL, but may contain interior NULs, so use the
  length.
- **Threads.** `sm_engine` and `sm_theme` are immutable and may be shared
  across threads. An `sm_session` must be used by one thread at a time.
  Sessions and token buffers do not borrow the engine or theme they came from.
- **Options.** Pass NULL for defaults, or start from
  `sm_html_options_default()`, `sm_ansi_options_default()`, or
  `sm_token_options_default()`. The option structs have no version field;
  adding a field is an ABI change.

### Tokens

`sm_engine_tokens` and `sm_session_line` return an `sm_tokens` buffer.
`sm_tokens_view` fills an `sm_token_view` with pointers to its flat arrays; no
data is copied:

```c
sm_token_options options = sm_token_options_default(); /* UTF-8 byte offsets */
sm_tokens *tokens = NULL;
sm_token_view view;
if (sm_engine_tokens(engine, "rust", 4, source, strlen(source), theme, &options,
                     &tokens) == SM_OK &&
    sm_tokens_view(tokens, &view) == SM_OK) {
    for (size_t i = 0; i < view.token_count; i++) {
        sm_style style = view.styles[view.token_styles[i]];
        printf("%u+%u fg=%06x\n", view.token_starts[i], view.token_lengths[i],
               style.foreground);
    }
}
sm_tokens_free(tokens);
```

Offsets default to UTF-8 bytes; set `options.unit` to `SM_OFFSET_UTF16` or
`SM_OFFSET_CODE_POINT` for other hosts. Lines split on `\n` only. With
`include_scopes`, `token_scopes` indexes stacks read by
`sm_tokens_scope_stack`. Colors are `0xRRGGBB` or `SM_NO_COLOR`; `modifiers`
combines `SM_BOLD`, `SM_ITALIC`, `SM_UNDERLINE`, and `SM_STRIKETHROUGH`.

## C++ API

```cpp
#include <iostream>
#include "syntaxmate.hpp"

int main() {
    namespace sm = syntaxmate;
    try {
        auto engine = sm::engine::bundled();
        auto theme = sm::theme::bundled("github-dark");
        std::cout << engine.ansi("rust", "fn main() {}\n", theme);

        sm::tokens tokens = engine.tokens("rust", "let x = 1;", theme);
        for (std::size_t i = 0; i < tokens.token_count(); ++i) {
            sm::style style = tokens.styles()[tokens.token_styles()[i]];
            std::cout << tokens.token_starts()[i] << " " << style.foreground << "\n";
        }

        auto session = engine.session("rust", theme, {sm::offset_unit::utf16});
        sm::tokens line = session.line("/* comment");
    } catch (const sm::error& e) {
        std::cerr << "error " << static_cast<unsigned>(e.kind()) << ": " << e.what() << "\n";
    }
}
```

`engine`, `theme`, `session`, and `tokens` are move-only owners. Inputs are
`std::string_view`, rendered output is `std::string`, and token arrays are
zero-copy `syntaxmate::span` views valid while the `tokens` object lives.
Failures throw `syntaxmate::error`, whose `kind()` is an `error_kind`.

## Tests

From the repository root:

```sh
nix develop -c nix shell nixpkgs#rust-cbindgen -c make -C bindings/c check
```

`check` verifies that `include/syntaxmate.h` matches cbindgen output, then
builds and runs [`tests/test_c.c`](tests/test_c.c) (shared library) and
[`tests/test_cpp.cpp`](tests/test_cpp.cpp) (static library) under
AddressSanitizer, LeakSanitizer, and UndefinedBehaviorSanitizer. The C++ test
also runs every [conformance case](../conformance/README.md) and compares the
output with `expected.json`. Other targets:

- `make -C bindings/c header` regenerates the header after an API change.
- `make -C bindings/c valgrind` runs both tests under valgrind instead
  (`nix shell nixpkgs#valgrind`).
- `make -C bindings/c check-install` installs to a scratch prefix and builds
  the C test with pkg-config.
- `PROFILE=release` uses the release library.
